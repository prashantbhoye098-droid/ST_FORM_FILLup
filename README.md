# mauliservices.in - आपले सरकार सेवा केंद्र व डिजिटल फॉर्म्स पोर्टल

माऊली डिजिटल सेवा केंद्र (पठावे दिगर, ता. बागलाण, जि. नाशिक)

## वैशिष्ट्ये (Features)
- अनुसूचित जमाती (ST) जात प्रमाणपत्र व वंशावळ शपथपत्र फॉर्म
- इतर मागासवर्गीय (OBC/SC) जात प्रमाणपत्र फॉर्म
- उत्पन्नाचा दाखला प्रपत्र-अ व स्वयंघोषणापत्र
- पॅन कार्ड अर्ज (नवीन Form 49A व दुरुस्ती CR-01) - फोटो व सही स्वयंचलित जोडणी
- १६ शासकीय स्वयंघोषणापत्रे
- Google AdSense Ready (Privacy Policy, Disclaimer, Terms, About Us, Scheme Guides)
- Razorpay Payment Gateway & Admin Control Panel

## Run Locally
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
```
The output will be in the `dist/` directory.
